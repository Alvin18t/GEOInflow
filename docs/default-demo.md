# 默认示例：猎看官网

默认示例网站名为“猎看官网（示例数据）”，域名为 `www.liekan.com`，网站 UUID 为 `b880cb21-e65a-4fdf-9c0e-3da5aed4e0fa`。它在数据库中设置 `is_demo=true`，界面与导出保留示例标识，浏览访问和抓取日志用于体验统计功能。

## 数据范围

仓库中的 `scripts/liekan-demo-data/official.ndjson.gz` 保存完整的默认示例记录，`manifest.json` 记录格式、数量、时间基准和 SHA-256 校验值。

| AI 与搜索蜘蛛日志 | 80,005 |

记录保留原示例的时间间隔、访客与访问会话的关联、页面分布、来源类型、地域和设备分布。首次导入将最新访问设为导入时间前 5 分钟，历史记录同步平移，因此新安装实例可以在当前日期范围查看示例。

数据包使用顺序编号关联访客和访问会话，导入时生成固定 UUID。账号、密码摘要、访问令牌、原始访客 IP、原 IP 哈希、访客自定义标识、URL 查询参数、广告点击标识、自动日志连接和 AI 对话均排除。营销标签与未知引荐域名采用明确的示例值。蜘蛛使用合成来源标识，验证状态为 `unverified`；已有分类版本保留，缺失分类证据保持缺失，抓取连续性和观测覆盖继续由实际证据决定。

## 初始化

完成私有环境配置与数据库迁移后运行：

```sh
pnpm liekan:seed-demo
```

使用 Docker 部署时，应用启动会完成迁移。随后执行：

```sh
docker compose -f docker-compose.liekan.yml exec app node scripts/liekan-seed-demo.mjs
```

导入使用已有的有效管理员作为网站拥有者，保持账号和密码完整。整个数据包在同一数据库事务中写入，并用数据库锁串行化重复运行；错误会回滚本次写入。导入同时更新统计缓存版本。

已经有浏览访问、日志、内容或目标的默认示例返回 `existing`，重复运行保留当前记录和日期。已删除的默认示例返回 `deleted`，通过软删除状态或保留的统计版本记录维持删除状态。UUID 被真实网站使用或网站名称、域名已经变更时，命令拒绝写入并提示冲突。其他网站、数据库历史及管理员凭据保持完整。

## 源码与验证

入口为 `scripts/liekan-seed-demo.mjs`，流式解析、标识生成、事务和保护条件位于 `scripts/liekan-demo.mjs`。运行时只需要既有的 Node.js、`pg`、`uuid` 和私有数据库配置，容器包含相同入口与数据包。

`src/lib/liekan/demo-seed.test.ts` 验证完整记录数量、匿名引用、日期平移、真实网站冲突、重复导入和删除状态。发布前还需在独立空库中执行完整导入，核对数量、示例标记、账号保持和重复运行结果。数据库备份与本地验收输出保存在 Git 忽略的私有目录。
