# 网站数据接入

网站设置的“数据接入”统一提供 JS 代码、Cloudflare 授权、服务器安装和继续检查入口。旧追踪代码与控制台检查地址继续打开当前网站的同一套引导。

接入进度通过 `/api/liekan/websites/{websiteId}/installation` 按网站保存。正常前进保存恢复步骤；跳过检查额外记录延后标记；完成设置记录首次完成时间。保存进度保持浏览访问、日志、导入记录和采集能力独立。只读角色可以浏览说明，修改进度需要完整登录及当前网站的管理权限。保存前在事务内重新核验权限。

保存响应到达时，仅在用户仍停留于发起保存的导航上下文时自动进入下一步。用户切换步骤、接入方式、网站或页面后，原请求的结果继续保存，页面保持用户的新位置。

选择日志方式时，立即更新当前流程的草稿和地址，使路由提交前后的步骤链接都携带本次选择。真实导航变更后，草稿由新地址接管。完成、汇总与检查页读取后台已保存的方式；历史地址中的方式参数保持流程草稿的用途。

检查使用网站创建至今的页面访问和已导入日志。示例网站的浏览访问与日志均标明数据性质，示例数据保持中性状态，并提示它们无法证明实际脚本或采集服务运行。读取失败、尚无数据、检查延后和实例未支持分别展示。

当前实例支持 JS 统计与手动日志导入。Cloudflare 授权及服务器一次安装入口展示实例能力，未配置真实授权应用、安装包、配对和持久日志接收服务时，生成按钮保持禁用。以后开放自动接入时，应同步更新能力契约和实际接收检查。
