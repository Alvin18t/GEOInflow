# 猎看统计系统说明

猎看统计将网站访客分析、AI 搜索引荐和蜘蛛抓取观察放在同一网站上下文中。系统基于 Umami v3.4.0，保留追踪协议、数据库兼容性和 MIT 版权，独立维护 GEO 界面、数据契约及增量迁移。

## 功能与数据来源

| 模块 | 用途 | 数据来源 |
| --- | --- | --- |
| 网站与追踪管理 | 管理网站、脚本接入、事件、安装进度 | 浏览器采集与已保存的配置 |
| GEO 与访客统计 | 总览、来源、地域、设备、内容和访问旅程 | 网站页面访问与会话 |
| AI 引荐 | 查看 AI 搜索引擎带来的真人访问 | 页面访问的引荐来源 |
| 蜘蛛分析 | 抓取概览、路径、覆盖、蜘蛛类型和身份验证 | 导入日志或已配置的自动日志来源 |
| 内容目录 | 导入 sitemap、CSV、JSON，核对内容与抓取 | 提供的内容清单和日志证据 |
| 目标与漏斗 | 衡量事件转化与路径推进 | 页面访问、自定义事件和保存的定义 |
| 协作与分享 | 个人／团队空间、看板、权限、公开报告 | 资源归属与实时授权 |
| AI 配置器 | 模型连接、网站上下文和对话 | 私有模型配置与已授权的网站资料 |
| 抓取控制 | Zone 验证、预览、确认和执行 | 独立来源凭据与提供方结果 |

浏览采集与日志接入独立工作。缺少输入、空数据、估算、部分缺口和未支持的能力分别展示，示例数据始终保留明确标记。抓取控制的预览、确认、租约和未知结果处理见 [抓取控制](crawler-control.md)。

## 源码结构

| 目录 | 职责 |
| --- | --- |
| `src/app` | Next.js 页面与 API 路由 |
| `src/components/liekan` | 猎看统计的页面组件与共享导航 |
| `src/lib/liekan/contracts` | 产品页面使用的数据契约 |
| `src/lib/liekan/upstream` | 上游查询、认证与权限适配 |
| `src/lib/liekan` | GEO、目录、日志、缓存、AI 和抓取控制逻辑 |
| `src/tracker`、`src/recorder` | 浏览器采集与行为录制 |
| `src/liekan-worker`、`src/liekan-agent` | 日志处理与服务器采集 |
| `prisma`、`db/liekan/migrations` | 上游结构与独立增量迁移 |
| `packages` | 保持兼容的 API 客户端和 MCP 包 |
| `config/liekan` | 上游基准、设计清单、覆盖规则和迁移校验 |
| `design/reference` | 已批准的界面参考与校验文件 |
| `scripts`、`tests` | 构建、迁移、示例初始化和验收 |

产品页面通过猎看契约访问数据，上游依赖集中在适配层。必要的核心改动记录在 `config/liekan/core-overrides.json`。新 SQL 迁移增量应用，使用后保持文件与校验值一致。

## 部署与首次体验

应用使用 Node.js 22.23.3、pnpm 12.3.4 和 PostgreSQL。Docker Compose 包含应用、日志处理进程、统计处理进程、Redis 缓存和独立数据库。AI 模块按环境配置启用，自动日志接入还需要公网 HTTPS 地址、安装资产或对应提供方配置。

安装时复制 `env.example` 到私有 `.env`，填写数据库和随机密钥。首次管理员为 `admin / liekan`；迁移保留已经修改的凭据。应用迁移后运行 `pnpm liekan:seed-demo`，导入随源码提供的“猎看官网（示例数据）”。操作步骤见 [本地部署](local-deployment.md)，数据范围见 [默认示例](default-demo.md)。

Git 仓库保存源码、冻结依赖清单、构建配置、测试、设计参考、文档和经过处理的示例数据。运行密钥、数据库卷、真实访客数据、备份、本地验收输出、构建产物和受独立数据许可限制的地理库按各自来源管理。
