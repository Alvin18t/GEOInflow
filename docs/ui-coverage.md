原型指纹在 design/reference/geo-stats-v3/manifest.json。全部 11 个文件保留原样。Liekan 统计区复用其布局、字体、色彩、侧栏、卡片、字段和 22 个图表形式。

| 原型 | 产品路由后缀 | 当前数据来源 |
| --- | --- | --- |
| index.html | /geo | Umami 浏览统计 + 日志 + 目标 |
| ai.html | /geo/ai | 请求分类、官方 IP 核验、月度占比、策略草稿 |

| human.html | /geo/human | 人类 PV/UV/会话、跳出、时长、设备 |

路由前缀为 /websites/{websiteId}，团队上下文沿用现有 URL。导出按当前页面、日期、筛选和排序生成 CSV，带 UTF-8 BOM 并防止公式注入。原型未定义的管理动作使用配套抽屉，网站管理、UTM 和目标配置沿用兼容内页。

## Umami 功能保留情况

以仓库固定的 Umami v3.4.0（ec0ff503）为对照：原有 60 个 page.tsx 路由全部保留，另有 11 个 Liekan 原型路由。路由数量包含登录、根入口、动态详情与拦截弹窗，不能直接当作独立产品页面数量。保留路由与接口证明代码仍存在；每项功能的交互、权限及有数据场景仍需要独立验收。

| 功能 | 当前 Liekan 状态 | 入口 | 后续新 UI 工作 |
| --- | --- | --- | --- |
| PV、UV、来源、地域、设备、页面与目标摘要 | 已进入 11 页原型 UI | /websites/{id}/geo | 保持已批准的布局、图表和字段 |
| 登录、2FA、个人资料、密码、API Key、偏好 | 功能保留；兼容内页 | /login、/login/two-factor、/settings/* | 登录与账户安全页、错误与到期状态 |

从 GEO 统计区进入兼容功能，先使用“返回管理后台”或已有“站点设置”“UTM 管理”“目标配置”按钮。兼容统计内页侧栏列出高级分析入口。原型的 11 项导航保持原样；后续入口扩展需单独批准。

能力缺口包括持续源站/CDN 采集、Filebeat/Kafka/ClickHouse、持久化日汇总与容量基准、自动保留期限与清理、大批量异步处理、rDNS 校验与官方范围自动刷新、正文接收完成证据、自动内容结构评分、真实访客首次访问识别、端到端阻断执行、搜索曝光/排名数据、完整转化跨域归因。这些能力不会用示例数据或假设值展示为已实现。

第一阶段保留原型内现有统计字段；字段是否可计算取决于输入证据。新访客、完成率、吞吐量等限制详见 data-definitions.md。原型未包含的内页布局不宣称完成逐像素还原。
