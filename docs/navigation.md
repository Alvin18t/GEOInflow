# 导航与页面层级

猎看统计按资源范围组织页面。全局管理提供工作台、网站管理、看板与分享、团队协作、链接与像素五个入口。选择网站后，侧栏切换为流量总览、AI 抓取分析、访客与来源、内容与行为、转化分析、深度分析、实时监测七个模块。

## 页面范围

| 上下文 | 主要内容 | 归属规则 |
| --- | --- | --- |
| 全局管理 | 网站、看板、团队、链接、像素和分享列表 | 列表默认个人空间，可切换团队；网站列表可查看全部可访问网站 |
| 当前网站 | GEO、访客、事件、转化及深度分析 | 必须明确网站，页头和侧栏显示名称、域名与所属空间 |
| 个人账户 | 资料、安全、API 密钥和偏好 | 位于侧栏底部，与网站选择独立 |
| 系统管理 | 所有用户、网站、团队及系统安全 | 系统管理员的独立管理上下文，保留实际后端权限校验 |
| 身份流程 | 登录、双重验证和恢复码 | 使用独立流程页面 |
| 公开分享 | 已授权的统计内容 | 使用分享资源与权限，独立于登录账户的侧栏 |

创建、编辑、安装验证、详情和播放器通过所属页面进入。常驻导航最多两层；模块文字进入默认页，右侧箭头负责展开和收起。页头显示当前位置，详情和流程页提供返回入口。

## 常用操作

- 网站管理进入网站统计或网站设置。网站设置包含基本信息、安装接入、采集设置、分享设置和危险操作五个分区。
- 当前网站侧栏顶部可切换网站、返回网站列表。切换网站保留日期，清除原网站的记录标识、分群和筛选；详情回到新网站的列表，未保存的编辑会提示。
- 看板、链接和像素通过自身资源标识获取来源和归属，网站选择对这些独立资源没有影响。工作台保留已保存的个人与团队来源。
- “分享当前网站”只展示和创建当前网站的分享链接。全局分享列表按所属空间展示网站、看板、链接和像素分享。
- 搜索、分页和排序条件写入列表地址，便于刷新、分享地址和返回列表。网站分析之间保留适用条件；进入暂不支持该条件的 GEO 页面时清除条件并显示提示。

## 日期、状态与文案

统计页显示实际期间与账户偏好的时区，默认 `Asia/Shanghai`。实时访客、日志更新和安装验证各自说明窗口。浏览接入成功以收到页面访问为依据；日志、内容目录和录制配置分别检查。真实零值、尚未接入、当前期间无数据、读取失败和实例暂不支持保持独立。

界面统一使用“访问记录”“访问详情”“行为人群”“UTM 活动”“API 密钥”“网站设置”。动作写明对象，例如“保存目标”“创建分享链接”“删除看板”。身份原因无法进一步确定的 401 显示“需要重新登录”，403 显示“没有访问权限”。

## 维护与验收

页面归属定义在 `src/lib/liekan/contracts/navigation.ts`，侧栏由 `src/components/liekan/Navigation.tsx` 统一渲染。路由适配集中在 `features/routes.ts`，上游请求通过 `src/lib/liekan/upstream`。新增功能先确定页面范围、上级页面、资源归属和状态，再接入导航。

原型 HTML 和指纹保持冻结。获批的导航、页头和文案变化使用 `config/liekan/navigation-ui.json` 独立验收；原主体图表、表格字段、面板和 VI 检查继续运行。响应式验证使用隔离浏览器，检查菜单数量、选中项、箭头留白、键盘操作、抽屉和页面溢出。完整验证和容器恢复流程见 [本地部署](local-deployment.md) 与 [上游更新](upstream-upgrade.md)。
