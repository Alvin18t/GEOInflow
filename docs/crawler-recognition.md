# 蜘蛛识别与规则兼容

身份目录维护稳定 ID、名称、厂商、用途与能力。HTTP 识别、官方范围核验、来源归因、robots 草稿和远端控制分别声明能力。名称表示请求声明的身份，核验状态单独展示。当前版本默认启用 53 个已复核 HTTP 请求标记，PetalBot 保持待复核，3 个 robots 用途控制项单独登记。Cloudflare 与 Nginx 控制仍限定原有 13 项。

## 网站规则

新站点及未改动的历史默认规则使用 `official` 模式，随应用更新默认目录。网站可保存停用 ID、分类覆盖与自定义规则。分类覆盖保留官方身份及 AI 请求资格。自定义名称与官方名称相同时仍使用独立未映射身份。

蜘蛛明细表、内容偏好列表与 CSV 在名称信息中标注“官方身份”或“自定义／历史未映射”，便于区分同名记录。身份标注表示目录映射，来源核验结论仍独立展示。缺少身份字段的旧版响应保留原展示格式。

页面排行保留主力蜘蛛的身份，估算抓取路径仅串联选中身份的记录。近期日志从采集时证据读取身份；缺失历史证据保持未映射，同名记录不据此获得官方身份。

显式空数组迁移为 `disabled`。改名、改序、删除或添加过的旧规则迁移为 `legacy`，保留原顺序与子串行为。迁移前内容保存在 `rules_migration_snapshot`。只修改 robots、白名单或展示偏好保持原规则模式。

编辑器默认保留网站规则模式。转换预览将完整名称、厂商和匹配词相符的旧条目映射为官方 ID，保留类型覆盖，其余条目保留为自定义规则及原匹配方式；未配置的官方条目保持停用。旧版顺序与包含匹配在转换后可能变化，用户核对预览后确认转换草稿，再保存生效。

新配置写入携带 `expectedRulesRevision`，并发旧版本返回 409。从旧模式转入官方模式需要转换预览后的 `conversionConfirmed`。新提交的旧格式规则补充明确匹配方式，无法通过四字段官方同名记录获得历史官方身份。迁移读取继续兼容真正的历史四字段记录。编辑旧规则时，在当前站点已存档且内容未改变的历史条目保留原身份；新增和修改的条目使用明确匹配模式。

## robots 与能力说明

robots 草稿仅使用厂商资料已确认的 token。观察目录、待复核条目不生成 robots 草稿或诊断判定；Bytespider 保留既有 Cloudflare/Nginx 控制能力。缺少 robots token 不影响 HTTP 识别。帮助目录分别显示资料收录、本版本识别能力、可核验范围、网站启用状态与范围健康；全局帮助页没有网站上下文时明确显示未选择与未读取。

解析、访问诊断和草稿合并共用 token 校验：RFC 9309 产品标记规则之外，仅兼容已启用目录中经过复核的完整 token（如 AI2Bot、360Spider、MJ12bot 和搜狗标记）。比较忽略大小写，内部空格保持精确匹配；拒绝任意带数字或空格的未收录标记以及控制字符。

## 事件与版本

规则版本包含匹配器版本、顺序、名称、有效身份、模式、分类与 AI 资格。档案按网站隔离。接收与配置更新使用同一网站锁，排队记录保存接收时分类，处理时不重新套用当前规则。事件标识和批次去重独立于分类版本。

日志的 AI 资格、识别状态、候选 ID、核验版本和观测时间均可为空，以支持旧日志及旧排队数据。缺少的历史证据保持未知。内置公开范围使用内容摘要版本，避免将核验通过与版本未记录混在一起。历史分类和核验结果不自动重写。

## 升级与兼容运行

迁移为追加式，已执行 SQL 不得修改。迁移登记摘要与发布迁移数量同步维护。部署前在隔离数据库验证迁移、重复运行、并发配置和重复导入。

兼容候选能够读取已登记的后续身份；详情目录附加实际观测身份。风险重算只修正候选版本支持的身份，保留其他身份的风险窗口与状态。日志 worker 的 `--pause-crawler-maintenance` 参数暂停范围刷新与风险分析的领取和发送，日志处理继续运行，已排队维护任务保留。协调应用与 worker 使用同一候选版本，恢复前移除此参数。

回滚保留已执行迁移和新增数据。仅使用完成新 ID、证据字段与排队任务演练的兼容候选；不能将直接重启 0.2.4 作为经过验证的无损回滚。公开范围快照无法补出历史脱敏 IP 已丢失的核验事实。

## 隔离验证

集成用例由 `LIEKAN_CRAWLER_TEST=1` 显式启用，严格要求本机端口 15440、数据库 `liekan_crawler_acceptance`。用例仅清理自身随机网站及事务内夹具，禁止对业务数据库执行重置。

## 官方范围与观测时间

当前使用 16 个固定 HTTPS 来源，绑定 26 个 HTTP 名称，具体名单见 [蜘蛛目录](crawler-directory.md)。Claude 共享范围绑定三种 Claude 身份，Google common 范围绑定其明确适用的九个 HTTP 名称。AhrefsBot 的范围不用于 AhrefsSiteAudit，Mistral 用户与索引范围不用于训练条目。Amazon 自动范围保持未接入。

内容摘要绑定来源、解析器、名称、稳定 ID 与规范化 CIDR。相同内容刷新沿用摘要，成功观测时间独立推进；304 需要已有合格缓存。每条日志保留核验时的版本及观测时间，后续更新不改写该证据。处理时间与事件时间分别使用七天窗口；未来观测时间、无效记录和缺失历史均不能获得新鲜证据。

范围快照与成功观测追加保存，当前指针、待复核候选和来源运行状态单独记录。更新失败保留旧快照及最后成功时间。超过旧条目数 50% 的增删变化，或任一地址族覆盖地址数超过四倍，进入待复核候选。新来源需要随审核版本提供初始基准。旧公共范围与已被日志引用的版本保留，不随当前指针切换删除。

抓取仅由维护进程进行，固定地址拒绝重定向，整体请求和响应体预算 15 秒，响应最多 1 MiB、原始范围最多 5000 条。空列表、错误 JSON、HTML 错误页、非法 CIDR、非公网及全地址范围拒绝激活。数据库外抓取、短事务提交，持久租约与代次保护旧任务结果；全局最多两个来源并发。

浏览器流量质量保留原六个已审核来源绑定及独立可信入口策略。新目录和新增范围不会扩大该信任策略。公开采集 payload 自报 IP 或身份不能建立可信来源。

## 持续维护入口

管理员在现有安全管理页面查看“蜘蛛来源维护”，包括内容版本、人工复核日期、最后尝试、最后成功、连续失败、下一次检查和待复核状态。IP 更新每小时运行，连续失败三次或 24 小时没有成功观测时告警，七天后证据过期。资料每七天检查，连续失败两次或 14 天未成功时告警。人工复核超过 45 天独立提示维护；自动抓取不会修改人工复核日期。

每周资料检查保存主体摘要与状态，变化形成复核待办。维护者每月对照官方资料审核名称、用途、停用及来源迁移，更新注册表、基准和测试后随应用版本发布。仅凭网页内容变化不能直接更新识别规则，也不发送外部消息。

维护者可运行 `pnpm liekan:crawlers:check-sources` 进行只读来源检查。该命令与维护进程共用来源检查器，不写数据库或运行规则。网络检查与确定性构建、单元测试分开执行；来源不可访问时报告实际错误。无需新增常驻服务、环境变量或外部账户。

网站“特征库管理”内可按需查询未知名称候选。查询最近七天已有未知请求，最多扫描 100000 条、五秒预算、展示 100 个候选；达到行数、时间或 10000 个不同 token 的处理预算时，显示已完成的部分样本及实际扫描时间。数据库查询未取得记录即超时，显示本次查询未完成。输出只含脱敏后的产品 token、次数与首次、末次时间，完整 UA、IP、路径不会出现在候选响应中。候选不自动获得厂商、AI 资格或可信身份。

帮助中心分别显示资料收录、本版识别、配置的核验范围和当前网站启用状态。站点信息只在完整登录且有网站读取权限的上下文查询；全局来源健康仅系统管理员可查。分享身份、未完成双重验证及公共采集身份不能读取这些维护接口。

## 恢复与验收

范围恢复使用 `restoreRangeSnapshot` 的受控维护调用，只允许同一来源、同一适用映射、已存在成功观测的合格历史版本。恢复沿用该版本已有的成功观测时间，过期版本继续显示过期；未通过的候选不能成为回滚目标。恢复操作会使正在运行的旧任务失效。

本次兼容回退基线采用阶段 B `c9765a540`，应用与 worker 同步切换并使用 `--pause-crawler-maintenance` 暂停范围和风险维护；该候选不领取后续版本新增的资料检查队列。阶段 A 仍按展示类型汇总 AI 请求，会将新版的 Google-InspectionTool 计入 AI，因此不列为本次回退目标。旧数据库表保留当前范围镜像，后续身份、排队批次和可选证据字段由兼容候选读取。迁移继续保留，禁止用旧备份覆盖切换后新接收的数据。恢复到当前版本后取消暂停并检查来源状态。

验收覆盖固定来源解析、304、异常变化阈值、失败恢复、历史版本、并发与过期任务、未知候选隐私与预算、完整会话权限、目录和生成一致性。完整发布门禁另行执行生产构建、Docker 迁移、API、隔离恢复、负载和中英文视觉检查；官方在线检查的失败与本地确定性测试分别报告。
